# To-Do List

A simple and aesthetic **To-Do List web application** built using HTML, CSS, and JavaScript. This project allows users to organize their daily tasks through a clean and user-friendly interface.

## Features

- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear completed tasks
- Displays the number of remaining tasks
- Saves tasks using browser Local Storage
- Tasks remain saved even after refreshing the page
- Responsive and aesthetic user interface

## Technologies Used

- **HTML5** — Provides the structure of the application
- **CSS3** — Used for styling, responsive design, and the aesthetic interface
- **JavaScript** — Handles task creation, deletion, completion, and other interactive functionality
- **Local Storage** — Stores tasks in the browser so they are not lost after refreshing the page

## What I Learned

Through this project, I practiced DOM manipulation, event handling, JavaScript functions, arrays, Local Storage, and connecting HTML, CSS, and JavaScript to create an interactive web application.
